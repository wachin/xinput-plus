# Debian packaging guide for xinput-plus

This repository's maintained Debian packaging workflow is documented in the
following focused guides:

- [Compile and test the Debian package](compile-and-test-deb.md)
- [Publish the package to Debian](how-to-publish-on-debian.md)
- [Create a local build](local-build.md)
- [Configure GPG keys for package signing](gpg-keys.md)
- [Understand the project and Debian changelogs](changelog-files-explained.md)
- [Understand `debian/watch` and `uscan`](watch-explained.md)

Together, these guides cover the package layout, build dependencies, source and
binary builds, quality checks, signing, mentors.debian.net, Salsa, sponsorship,
and ongoing package maintenance. Keeping the instructions in focused documents
avoids maintaining a second, overlapping packaging tutorial.
